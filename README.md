# ระบบสรุปเวร ER

เว็บแอปบันทึกและสรุปเวรของงานอุบัติเหตุและฉุกเฉิน ใช้ Google Sheets ที่เก็บคำตอบของฟอร์ม "สรุปเวร ER" เป็นฐานข้อมูล

- **แดชบอร์ด:** ผู้ป่วยรายวันแยกเวร, Triage 5 ระดับ, การจำหน่าย, ภาระงานตามวันและเวร, Fast track, เวรที่ขาดบันทึก และปัญหาในเวร
- **บันทึกเวร:** กรอกบนมือถือได้สะดวก มีตัวตรวจผลรวม Triage และการจำหน่ายเทียบยอดรวม และปุ่มเลือกชื่อเจ้าหน้าที่
- **ประวัติ:** แก้ไขหรือลบเวรได้ ทุกการเปลี่ยนแปลงเขียนลง Google Sheets ทันที และส่งออกเป็น CSV ได้
- คำตอบที่ส่งผ่าน Google Forms ตามเดิมจะแสดงบนเว็บด้วย เพราะใช้ชีตเดียวกัน

พัฒนาโดย **นายทวี แสนสนอง** หัวหน้างานอุบัติเหตุฉุกเฉินและนิติเวช

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ (เปิดผ่าน GitHub Pages) |
| `apps-script/Code.gs` | API บน Google Apps Script สำหรับอ่าน เพิ่ม แก้ไข และลบแถวในชีตคำตอบ |

## ติดตั้ง (ทำครั้งเดียว โดยเจ้าของชีต)

### 1. ติดตั้ง Apps Script ในชีตคำตอบ

1. เปิดชีต **สรุปเวรปีงบ 2569 (การตอบกลับ)** ด้วยบัญชีเจ้าของชีต
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs) แทน จากนั้นกดบันทึก
4. ตั้งรหัสผ่านของทีม: ไอคอนเฟือง **การตั้งค่าโปรเจ็กต์** → **พร็อพเพอร์ตี้ของสคริปต์** → **เพิ่มพร็อพเพอร์ตี้**
   - พร็อพเพอร์ตี้: `ACCESS_KEY`
   - ค่า: รหัสผ่านที่จะแจกให้ทีม ควรยาวอย่างน้อย 8 ตัวอักษร
5. กด **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** แล้วเลือกประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** (เจ้าของชีต)
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
6. กด **ทำให้ใช้งานได้** แล้วอนุญาตสิทธิ์ที่ Google ขอ
7. คัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`

> ทุกคำขอต้องมี `ACCESS_KEY` ที่ถูกต้อง คนที่ได้ URL แต่ไม่มีรหัสผ่านจะอ่านหรือแก้ข้อมูลไม่ได้

### 2. ใส่ URL ในหน้าเว็บ

เลือกวิธีใดวิธีหนึ่ง:

- **ใส่ในไฟล์ (แนะนำ):** เปิด `index.html` ค้นหา `const DEFAULT_API = "";` แล้ววาง URL ลงในเครื่องหมายคำพูด ผู้ใช้ทุกคนจะกรอกแค่รหัสผ่าน
- **ใส่ในหน้าเว็บ:** แท็บ **ประวัติการบันทึก → ตั้งค่าการเชื่อมต่อ** แล้วกรอก URL และรหัสผ่าน (จำไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น)

### 3. เปิดใช้ GitHub Pages

ใน repository ไปที่ **Settings → Pages** เลือก **Deploy from a branch**, branch `main`, โฟลเดอร์ `/ (root)` แล้วกดบันทึก
รอประมาณ 1 นาที เว็บจะเปิดได้ที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repository>/`

## เมื่อแก้โค้ด Apps Script

กด **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (ไอคอนดินสอ) → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้**
วิธีนี้ URL เดิมยังใช้ได้ ถ้าสร้าง "รายการใหม่" จะได้ URL ใหม่และต้องแก้ใน `index.html`

## หมายเหตุการทำงาน

- **การแก้ไขบนเว็บ** เขียนทับแถวเดิมในชีต และเก็บเวลาที่ส่งฟอร์มไว้ตามเดิม
- **เวรที่ส่งฟอร์มซ้ำ** เว็บแสดงคำตอบล่าสุดพร้อมป้าย "ส่งซ้ำ" การลบจะลบทุกแถวของเวรนั้น
- **ป้องกันแก้ผิดแถว:** ก่อนแก้หรือลบ ระบบตรวจว่าแถวยังเป็นเวรเดิมอยู่ ถ้ามีคนเรียงหรือลบแถวในชีตไปก่อน ระบบจะแจ้งให้โหลดข้อมูลใหม่แทนการแก้ผิดแถว
- **อัปเดตอัตโนมัติ:** หน้าเว็บโหลดข้อมูลใหม่ทุก 2 นาที
